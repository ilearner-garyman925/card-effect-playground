# 角色工序與驗收

## 1. 角色定稿先於拆件

輸入可以是完整場景或單獨人物。記錄角色不可改動的髮型、臉、衣服、配色、道具、比例；只在需要時詢問未知設定。對多個人物，先用統一展示尺度做正面／三分之二正面站姿，保留腳底和頭頂空間。

若使用者已接受某張人物圖，以該圖為身份參考。不要以「去背」名義改臉、改服裝或美化身材。AI 去背和拆件可能有重繪漂移，要與原圖並排檢查。

## 2. 最小足夠拆件

- **簡單待機**：完整透明人物＋網格權重即可，適合呼吸和小幅重心移動。
- **低頭／望向某物**：軀幹（含靜止手臂和腿）、獨立頭部、活動手臂＋握持道具。需要改視線時補頭部姿勢。
- **明顯彎肘／揮手**：再拆上臂、前臂、手；補被遮擋的肩、肘和胸側。沒有這些素材，不能靠拉伸整隻手臂模擬大幅關節轉動。

只拆會動的部分。硬鎧甲、手持平板、武器應作剛性部件；變形集中在關節過渡。頭部轉動應盡量以剛性旋轉加少量頸部過渡，而非讓整張臉變扁。

透明 PNG 使用真正 alpha；檢查髮絲、手臂內側、腿間及道具空隙。不要裁切每個零件後直接拉伸成同尺寸。

推薦所有部件保留相同全幅透明畫布；若用緊裁圖，必須記錄 trim offset、原始尺寸和 pivot。姿勢圖集每格尺寸相同，但仍須校準各格的頸部位置，不能假設同格尺寸代表同軸心。

## 3. 背景不依賴人物

完整場景去人後，補人物遮住的管道、道路和建築，並移除原人物的地面倒影和陰影。陰影與新角色倒影由合成時新增，不烘焙進可共用背景。

移動的飛行器、葉片等需獨立資產及乾淨後方；不要移走道具卻留著原本的影子、光束或輪廓。依場景需要拆遠景、主要背景、前景遮擋，不為每張圖強制拆很多層。

## 4. 動作模板與角色綁定分開

動作模板保存「看目標 A → 看目標 B → 返回」的時間、角度和緩動；角色 rig 保存頸、肩、肘、腰、腳的座標與可動範圍。模板在新角色上要重新綁定。

先做低成本待機循環，再加入符合角色的主動作。持平板角色可沿用六秒看平板／望飛行器循環；其他角色的目標應按其道具與場景改動。背景沒有高空載具時，不沿用假定有載具的視線。

實作要點：
- 移動上半身的共同父層，再局部轉動頭和手臂，避免分層分離。
- 腳底權重歸零；軀幹位移平滑過渡到腿部。明顯大幅動作需腿部骨架，不能無限提高擺動幅度。
- 使用連續緩動，例如 quintic smoothstep；停頓前後速度平順。可給手臂約 0.1 秒跟隨延遲，依效果調整，非固定規範。
- 首尾姿勢與速度相接。六秒循環只是此基準的設定。
- 原型三姿勢混合能減少跳換，但中途可能雙眼／髮絲重影。要求更高時補中間姿勢，或做對齊網格形變；不能只延長淡化。
- WebGL 共享頂點網格優於逐條 Canvas 影像切片；後者在本專案已出現細橫線。

## 5. 卡面外殼

Canvas 播放角色和環境；外層負責 perspective、hover tilt、正反面；箔光、高光、粒子為獨立 pointer-events:none 覆蓋層。文字卡框與角色素材不烘焙在一起。

卡牌點擊／Enter 翻面；觸控拖動時不誤觸翻面，允許頁面滾動。不承諾裝置傾斜感應，除非實際實作並測試權限與裝置支援。保留暫停、減少動態偏好、清晰 focus。

## 驗收

1. **素材**：去背真透明；三個主要姿勢可對齊；服裝和臉沒有不合理變化。
2. **關節**：純色背景看頸肩肘沒有漏底、雙重關節或切邊；剛性道具不融化；腳底不滑。
3. **動作**：看正確的目標，動作在預覽尺寸可看見；首尾不跳；過渡無明顯重影。對不能排除的重影如實說明。
4. **合成**：地平線、角色尺度、接地陰影及光色合理；背景無舊人物殘留；前景遮擋正確。
5. **卡面**：hover 光的位置有變，離開後回正；正反面不穿透；點擊與鍵盤可翻回；人物在正面繼續動。
6. **效能與操作**：正常尺寸和窄視窗可用，沒有缺圖或腳本錯誤；暫停／恢復正常。若換渲染技術或有卡頓疑慮，再量測性能，不無依據宣稱固定幀率。

交付前實際觀察至少一輪循環和兩個極端姿勢。未做的檢查標明，不用「已全面驗證」概括。
