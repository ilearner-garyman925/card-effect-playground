# 合格版本基準

使用者在 2026-11-17 對黑銀閃箔遊戲卡表示「目前這版合格」。資產快照來自本機 `C:/xampp/htdocs/yuki-card-playground/cyber-card/` 的 game.html、game.js、acting.js 與所需圖片；後續以 skill 內可攜快照為準，不依賴原路徑存在。

## 檔案職責

- `game.html`：卡牌前後面及操作面板，包含樣式，避免原簡易伺服器 CSS MIME 問題。
- `game.js`：CSS 3D 傾斜、平滑追蹤游標、高光、點擊／Enter 翻面、觸控拖曳抑制誤觸。
- `acting.js`：獨立頭、身、持平板手臂合成；quintic 緩動；WebGL 共享頂點網格擺動；腳底固定；雨、光與載具。
- `body-v2.png`：軀幹、腿及靜止手臂；`arm-v2.png`：活動手臂連平板。
- `heads-v2.png`：正面／低頭／向上望三格圖集。
- `background-v1.png`：已移除角色與載具的乾淨街道。
- `B.jpg`：原始參考，示範目前仍從此圖裁切載具。

## 不能照搬的部分

1. `neck={461,387}`、`shoulder={545,427}`、頭部目標矩形以及人物下半身網格權重都是目前角色專用。
2. `ship` Path2D 是 B.jpg 右上角載具的原圖座標。背景庫正式化時，應改獨立道具資產，或在不需載具的背景停用；不可把新背景上方隨機區域當載具。
3. 三張頭部圖用短暫混合過渡，會有局部重影風險；這不等於連續三維轉頭。要求更自然時需要中間姿勢或臉部 rig。
4. 身體擺動是上半身位移，過渡到腿部；不適合走路或大幅扭腰。
5. 頭部、手臂依原始 PNG 全幅對齊；新資產若重新置中就會錯位。
6. 改 HTML 內的樣式才會改這個快照的卡面；不要改不存在的外掛樣式檔後聲稱已生效。
