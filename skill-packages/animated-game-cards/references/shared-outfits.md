# 共用衣著、頭頸與前後髮

此流程以使用者已接受的森林服共用身體版本為依據，是之後新增角色的預設。素材庫的暫時瀏覽介面不屬於本流程。

## 資產責任

- **身份包**：臉、頭頸、後髮、前髮及動作需要的頭部姿勢。短髮可省略不需要的髮層，不必強拆。
- **衣著包**：同一份身體、衣領、肩甲、手臂、雙手、腿部和人物持有道具；附頸部接點、遮罩及可動範圍。身體包含皮膚的部位也先保持原樣；有改膚色或體型需求時明確製作新版本。
- **搭配綁定**：身份 × 衣著的頭部尺度、位置、頸部接點、髮層偏移、遮擋邊界及支援動作。不能假設所有頭型或衣領共用一組數值。
- **背景、特效、紋理、卡框**：分開管理；換身份不重新生成或修改它們。

## 頭部定稿與確認

先在固定衣著、站位和展示尺度下製作靜態原型，按需要比較頭部大小、正面／微側面及神情。記錄「畫面左／右」，避免角色自身左右的歧義。使用者確認方向後才製作頭頸、前髮、後髮；不要將未確認的生成變體當成正式身份素材。

生成圖可能重繪衣著，這類原型只用於頭部觀感比較；接入時必須回到原共用衣著。拆件也可能改變樣貌，因此原型批准不自動代表拆件或所有衣著搭配已批准。分別保存原型、分層素材版本、各衣著綁定與接入後的確認狀態；有新回覆確認時更新紀錄，不能一直保留「待確認」。

比例與角度以已接受圖像為準。「縮小約 12%」「左轉 5–8°」是本次 G 版的設計目標，不是所有角色的固定規格。程式把圖層畫布縮為 88%，不代表重繪後的實際臉寬也精確縮小 12%；分別記錄視覺目標與實際綁定值。

## 製作次序

1. 鎖定已接受的衣著來源並保留原檔。優先以透明遮罩從原人物分出頭頸和衣著，不重新生成整套服裝。衣領造型、肩甲輪廓、寶石、配色、接縫與身體比例均保持不變。
2. 衣著只拆一次。原頭部遮住的必要區域如需補畫，作為衣著包的新版本處理、對照原圖確認；不要每個身份各補一套服裝。沒有補好的隱藏區域，就限制會露出該區域的動作。
3. 依人物參考製作頭頸、後髮、前髮，避免把原衣服或另一套領口烘焙進頭部圖。使用真 alpha，保留一致畫布或完整記錄裁切偏移。前後髮分界依肩甲的遮擋關係決定，而非單純把頭髮左右切開。
4. 在固定衣著尺度下校準頭部，讓頸部下端延伸到衣領後方。檢查下巴、頸長、頸寬、光色及肩膀比例；頸部看起來異常時，分辨是素材解剖、對位還是遮擋問題，不能只調 z-index。需要重繪時限於頭頸／髮層。
5. 先確認靜態接合，再接共同待機。需要低頭、抬頭或側轉才新增相應姿勢、接點與遮罩；逐個極端姿勢驗收，不能假設中立姿勢合格就能大幅轉頭。

## 後到前的合成順序

```text
後髮
頭部與頸部
共用衣著（含遮住頸根的衣領、肩甲）
前髮
```

後髮在肩甲後；垂到胸前的髮束覆蓋衣著。髮束遮住肩甲不等於肩甲素材改變。衣領也可抽成獨立前景遮擋層，但必須來自同一衣著版本，不能隨身份換成另一領口。

各層先在同一邏輯畫布對齊，再一起接受共同身體變形，避免待機時頸髮分離。局部頭部動作需讓前後髮跟隨頭部接點，同時保持正確遮擋；這不等於已具備頭髮物理或碰撞。衣著的整體尺度與站位由衣著／配方控制，身份只校準頭頸與頭髮，避免換人時整個身體忽大忽小。

## 驗收共用是否成立

1. 確認不同身份引用同一衣著資產／快取與版本，沒有暗中切換全身圖。
2. 隱藏頭頸及前後髮，固定動畫時間、衣著尺度、站位和光效，再切換身份。衣領、肩甲和身體應完全一致；可比較同條件的衣著區域像素。比較範圍及條件需如實記錄。
3. 恢復頭髮，以棋盤底和最終背景檢查髮絲透明邊、脖子漏底、雙領口、頸根切線、肩甲錯誤覆蓋及不同畫風的接合。
4. 檢查至少完整一輪待機及支援動作的極端姿勢，確認前後髮跟隨、衣領持續遮住頸根。最後再加回視差、特效及閃箔，不能靠強光遮住接縫。

森林服既有驗證在固定時間、關閉視差／傾斜／閃箔且隱藏頭髮後，所比較的衣領肩甲身體區域 RGB 差異為 0；這不是所有角度或所有動作已驗證的保證。

## 共用身份跨衣著 QC

- **樣貌**：把拆件合成與已確認原型對照，檢查五官、笑容、髮型和朝向；用相近臉部展示尺度比較，避免縮圖掩蓋漂移。
- **衣著**：依前節方法隱藏身份層，固定時間、尺度與光效，確認衣領肩甲沒有因換人而改變。
- **接合**：關閉閃箔，先看完整角色，再隱藏前後髮檢查頸長、下巴、頸根、透明邊及遮擋；不要讓髮束或強光遮住缺口。
- **動作**：觀察完整循環及支援動作的兩端姿勢，檢查漏底、分離、穿插與首尾跳動。沒有測過的姿勢不能記為已通過。
- **跨衣著回歸**：修改共用身份圖集後，重看所有已接受且受影響的搭配；本專案至少包含賽博服、森林服與仙俠服。只改某套專用綁定時，重驗該搭配並確認其他搭配未被誤改。不為增加新角色而重設已接受衣著。

交付紀錄分開列出程式／視覺檢查、使用者確認及尚未驗證的限制；暫時素材庫介面不納入製作流程。

## 已確認的仙俠服與獨立特效

C.jpg 的原型及分層接入已分別獲使用者確認；接入確認日期為 2026-11-19。專案詳錄在 `cyber-card/character-studies/xianxia-integration-v1.md`，以下檔名為專案線索，非 skill 內置素材。

- `xianxia-person-v1.png` 是從 C.jpg 去背景、去法術並補衣料後的單一來源。去背／補畫有重繪，不能聲稱與 C.jpg 逐像素相同；「共用」是指兩身份引用同一份完成後的衣著。
- 以來源座標遮罩 `xianxiaBoundary`，透過 destination-out / destination-in 得到共用 `xianxiaOutfit` 與原藍髮 `xianxiaBlueHead`。保留交領、金紋、寬袖、腰帶及雙手，不為長髮角色另做一套長袍。
- 長髮接入 G 頭頸與前後髮，使用上列仙俠專用接點。交領開口要依實際皮膚／衣料邊界校準，不硬套高領鎧甲遮罩。衣著縮放0.90、鍵 shared:xianxia:v1 與身份頭部尺度分開。
- `cloud-mountains-v1.png` 是移除人物及全部青藍光效後的乾淨雲海背景；保留可站立石台。舊法術和人物殘影不得留在背景或衣料上。
- `effects.js` 的 qi（青藍御風）是獨立程式光帶／粒子。以同一動畫時鐘和曲線深度分成 back/front 兩次繪製，後半被人物遮住，前半覆蓋人物。隨身法術跟隨人物尺度、位移及視差；雨等環境效果沿用自己的深度層。

新衣著附帶的特效應可獨立啟閉、疊加及跨衣著使用，不能依衣著選項強制烘焙。程式光效屬低成本動態詮釋，不宣稱逐幀還原原圖。特效也有自己的週期，不因角色待機六秒便假設所有粒子六秒無縫循環。

### 獨立特效與新衣著 QC

1. 關閉特效，檢查衣料補畫、背景乾淨度、交領和手指；再隱藏髮層檢查頸根。閃箔也關閉，避免遮住接縫。
2. 固定時間及尺度比較兩身份的衣著；如果未實際量測像素差異，只記錄同源素材及目視結果，不沿用其他衣著的「差異0」結論。
3. 開啟特效觀察前後穿越及粒子邊界，檢查縮放、視差、暫停／恢復與完整特效週期；再測試獨立關閉、跨背景／衣著及多特效疊加。逐項記錄完成範圍。
4. 共用身份素材一旦改動，回歸檢查三套已確認衣著。只新增專用綁定或獨立特效時，避免順手重繪已接受身份。
