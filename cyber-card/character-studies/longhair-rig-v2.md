# 長髮賽博角色分層 v2

素材：`../longhair-layers-v2.png`，內建 imagegen 生成，透明三格圖集。
完整提示詞：`longhair-layers-v2-prompt.txt`。

由左至右：頭部／頸部、前髮、後髮。頭部格保留短側髮，前髮格包括覆蓋頭頂的髮片；三格各自校準中心，不能直接假定圖集格中心就是頸部軸心。

渲染順序：後髮 → 共用身體 → 共用手臂 → 頭部／頸部 → 衣領前緣 → 前髮 → 整體人物網格。

`library-renderer.js` 的 `longhairRig` 保存角色圖層尺寸、位置和頸部軸心。`cyberCollarFront` 是賽博服裝專用遮擋輪廓，從原 `body-v2.png` 重繪衣領前緣，並重用相同藍光遮罩。衣領跟隨軀幹，頭部與前後髮共享較小幅度的頸部旋轉；頸部延伸在衣領後方，避免轉動時露底。

衣服、手臂和平板仍使用既有素材，沒有為長髮角色重畫身體。藍髮角色沿用原有頭部姿勢圖集；德魯伊尚未轉成此分層結構。

這版是平面分層旋轉，尚非三維轉頭、眼神追蹤或頭髮物理模擬。換衣著時須另外校準該服裝的頸部接點與衣領遮擋輪廓。

驗證：瀏覽器中以棋盤底、關閉箔光、隱藏前後髮，在 1.8 倍動作幅度檢查 1.5 秒與 3.8 秒偏轉接位；再恢復前後髮檢查肩甲遮擋。
