# 賽博共用衣著 v1

兩位身份固定使用相同 `body-v2.png`、`arm-v2.png`、鎧甲光效及手臂動作。移除完整長髮人物圖的渲染分支與比較開關，人物遠近改為共用 `shared:cyber:v1`；森林服保留 `shared:druid:v1`。原圖未覆寫。

合成順序：後髮 → 頭頸 → 共用身體與活動手臂 → 前髮 → 共同網格變形。整份身體提供衣領遮擋，不再使用長髮專用的局部衣領補蓋。

藍髮沿用 `heads-v2.png` 三姿勢圖集，Canvas 遮罩排除圖集內的衣領，並調整低頭的垂直對位，避免固定高領遮住下巴。短髮保留在頭部層；長髮使用既有頭頸 v3、前後髮 v2 與賽博專用接點。長髮仍是同一臉部圖的小幅偏轉，並非三視角臉部動畫。

驗證：JS 語法檢查通過；瀏覽器檢視正面及兩端姿勢。固定時間 0、100% 人物遠近，關閉閒置傾斜、視差及閃箔，再選「只看共用衣著」。兩身份截圖中 (440,350) 至 (640,600) 的衣領、肩甲與身體區域 RGB 差異為 0。這是指定區域與條件的對照，不代表所有動畫幀已做逐像素比較。

本次為本機原型，未推送或部署。
