# G 版森林服接入 v1

沿用賽博服已確認的 `longhair-g-layers-v1.png` 頭頸、前髮、後髮圖集，不重新生成角色或服裝。

森林服專用綁定：size=378.4（舊圖層畫布 430 的 88%）、top=198、水平中心 0.51、neck socket=(478,429)。此為圖層畫布尺度，非宣稱臉寬精確縮小 12%。賽博的既有 G 綁定維持不變。

仍由原本 `druidOutfit` 提供完整衣領、肩甲與身體遮擋；合成順序是後髮 → 頭頸 → 原衣著 → 前髮。保留共用施法待機及森林服縮放設定。比較舊版頭頸時使用原 v3 頭頸和 v2 髮層，方便對照。

已檢查 JS 語法、瀏覽器完整合成及棋盤底隱藏前後髮的頸部接合。預覽預設改為長髮森林服、森林背景及自然魔法。僅本機修改，未部署；使用者已在查看結果後回覆「效果不錯!」，確認此 G 版森林服搭配。
