# 德魯伊共用衣著 v1

唯一衣著來源：`../druid-person-v1.png`（1086 × 1448），即原本藍髮德魯伊。
原圖未重新生成、改色或覆寫。`library-renderer.js` 以原圖座標中的 `druidHeadBoundary`，建立兩個 896 × 1200 的透明 Canvas 快取：

- `druidOutfit`：原圖扣除頭髮、臉及頸部開口；保留原衣領、肩甲、身體、雙手、腿甲。
- `druidBlueHead`：相同邊界內的原藍髮頭部／頸部。

兩位角色均繪製同一個 `druidOutfit`。藍髮角色接回原頭部；長髮角色使用既有頭頸 v3 與前後髮 v2，經森林服專用接點及尺度對齊。繪製順序為後髮 → 頭頸 → 原衣著（包含衣領遮擋）→ 前髮。

衣著與皮膚邊界是人工校準遮罩，沒有生成第二套服裝；長髮可能遮住部分肩甲，但不替換肩甲素材。原圖沒有露出的衣領後側未憑空補畫，因此此版先保留共同施法待機，未新增大幅獨立轉頭。

森林服兩位角色共用遠近設定 `shared:druid:v1`，切換人物不改變身體大小。舊版各人物縮放數值未刪除。其他背景、特效、紋理仍獨立。

「動畫調整 → 人物分層檢查 → 只看共用衣著（森林服）」可隱藏頭部與前後髮，檢查兩位角色的衣著是否相同。

本次僅更新本機，未推送或部署。

驗證：本機瀏覽器固定時間 0、關閉閒置傾斜／視差／閃箔、棋盤底、只看共用衣著。切換角色後比較畫面 (390,320) 至 (650,600) 的衣領、肩甲、身體區域，RGB 差異像素數為 0。
